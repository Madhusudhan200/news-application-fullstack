# NAA TV Telugu — Official News Applications Ecosystem

Complete master workspace for **NAA TV Telugu** (`com.naatvtelugu.news`).

---

## 📱 Ecosystem Components

1. **Native Android Application** (`NaaTvTelugu/` & `news-application-frontend/android`):
   - Jetpack Compose, Material 3, Kotlin Coroutines & Flow
   - Full Way2News reference UI with customized themes, categories, and real-time offline caching
   - Direct APK: `NaaTvTelugu.apk`

2. **Native iOS Application** (`NaaTvTelugu-iOS/` & `news-application-frontend/ios`):
   - SwiftUI, Swift 5.0, Combine, iOS 16.0+
   - Exact parity with the 4 reference designs (Explore, Watching, Categories Sheet, More Profile)
   - Master Admin Panel with typography sliders, logo resizing, and staff work status controls
   - Automated CI/CD builders for `.ipa` generation via Codemagic and GitHub Actions

3. **Backend API Service** (`news-application-backend/`):
   - Node.js & Express REST API with WordPress live proxy & caching
   - Reporter field upload endpoints, pending approval queue, user directory, and work status management
   - Docker & Docker Compose containerization
